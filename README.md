# TechStore — адаптивный интернет-магазин электроники

## Описание
Многостраничный адаптивный сайт интернет-магазина электроники TechStore. Проект выполнен в рамках контрольной работы №3 на основе HTML/CSS-проекта из КР №1 (без использования Bootstrap).

## Технологии
- **HTML5**: семантическая разметка (`<main>`, `<nav>`, `<article>`, `<aside>`, `<header>`, `<footer>`)
- **CSS3**: Flexbox, CSS Grid, CSS-переменные, методология БЭМ, **медиазапросы**, подход **Mobile First**
- **Доступность (a11y)**: skip-link, видимый фокус, ARIA-атрибуты, семантика
- **Оптимизация**: responsive images (`srcset`, `sizes`, `loading="lazy"`)
- **Инструменты**: Lighthouse (проверка доступности)
- Минимум JavaScript (только для открытия/закрытия модального окна)

## Как запустить
1. Клонируйте репозиторий: `git clone https://github.com/cxlevi/kr3-responsive-shop`
2. Откройте `index.html` в браузере или перейдите по ссылке на GitHub Pages.
3. Для проверки адаптивности используйте DevTools (F12) → Toggle Device Toolbar и проверьте ширины: 360px, 480px, 640px, 960px, 1280px.

## Адаптивные решения (Mobile First)
1. **Подход Mobile First**: базовые стили в `responsive.css` написаны для мобильных устройств (360px), расширение происходит через медиазапросы `@media (min-width: ...)`.
2. **Медиазапросы**: реализованы брейкпоинты 430px, 768px (планшет), 1024px (небольшой десктоп), 1440px (широкий десктоп).
3. **Навигация**: на мобильных устройствах реализовано бургер-меню, которое раскрывается по клику; на 768px+ меню становится горизонтальным.
4. **Сетка карточек**: плавное перестроение `grid-template-columns` от 1 колонки (мобильные) до 4 колонок (широкий десктоп).
5. **Каталог и фильтры**: на мобильных устройствах блок фильтров (`aside`) располагается над товарами в одну колонку, на 768px+ фиксируется сбоку (`position: sticky`).
6. **Формы**: на мобильных устройствах все поля формы выстраиваются в одну колонку с увеличенной областью нажатия (16px шрифт для предотвращения зума на iOS).
7. **Таблица характеристик**: обёрнута в контейнер `.table-wrapper` с `overflow-x: auto`, что предотвращает горизонтальный скролл всей страницы на мобильных устройствах.
8. **Responsive Images**: добавлено глобальное правило `img { max-width: 100%; height: auto; }`. Для главного изображения товара и карточек каталога использованы атрибуты `srcset` и `sizes` для загрузки оптимального размера изображения в зависимости от ширины экрана.

## Исправления и улучшения доступности (Accessibility)
1. **Skip-link**: добавлена скрытая ссылка «Перейти к основному содержимому», которая появляется при навигации с клавиатуры (Tab).
2. **Видимый фокус**: для всех интерактивных элементов (ссылки, кнопки, поля ввода) настроен чёткий `:focus-visible` с `outline`.
3. **Семантика**: на каждой странице ровно один `<h1>`, соблюдена иерархия заголовков (`h1` → `h2` → `h3`).
4. **Формы**: все поля `<input>`, `<select>`, `<textarea>` связаны с текстовыми подписями через атрибут `for` у `<label>`.
5. **Изображения**: у всех тегов `<img>` прописаны осмысленные атрибуты `alt`, описывающие содержимое. Декоративные элементы (эмодзи) скрыты от скринридеров через `aria-hidden="true"`.
6. **Lighthouse**: проведена проверка страниц `index.html`, `catalog.html`, `order.html` в категории Accessibility. Выявленные замечания устранены. Скриншот отчёта сохранён в папке `lighthouse/`.
